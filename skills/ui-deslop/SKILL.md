# 去 UI slop

核心一句：**Let the layout do the explaining.** 模型写界面时习惯把界面当说明书写，给每个模块都配一句解释。专业用户要的是信息本身，含义由位置、分组、字号和留白传达。

## 删除测试

每个不是数据本身的元素都过这一道：

> 删掉它之后，目标用户会**看错数据**、**做错操作**，或者**在异常状态里无路可走**吗？

- 三个都不会：删。
- 有一个会：留下，压到最短，并检查能否改由布局或渐进展开承担。
- 同一页已经表达过同一信息：只留最靠近用户视线的那一处。

新增元素同样过这道测试，并先问：调整或删掉现有元素能否达到同样目的？

精简只做减法和重排：页面上的事实以原文为准，原页面没写明的范围或口径列为待确认。

## 步骤

### 1. 定场景

确认三件事：用户是谁、这个界面已有的设计 token 和组件、要动手改还是只出清单（用户说「先看看」或只给截图时只出清单，第 3、4 步跳过）。

默认按专业用户处理。C 端新手引导、低频高风险流程（报税、医疗、开户）的解释性文字更有价值，删除测试里的「做错操作」从严判断。

完成标准：能用一句话说出目标用户，以及这个用户每天看这个界面的频率。

### 2. 逐元素过账

列出页面里全部非数据元素：标题、副标题、说明、提示、徽章、图标、状态点、边框、容器、装饰。每一项给结论：**删 / 留 / 合并 / 收进渐进展开**。对照下方「常见 slop」和「必须保留」。

生成新界面时反过来走：先只写数据、标题和操作的骨架，每加一个元素都过一次删除测试。功能范围以用户的请求为准：要列表就交付列表，详情页、批量操作、危险操作流程这类想法写进汇报，由用户决定。

完成标准：清单里每一项都有结论，每个「留」都写明它防止了三种后果里的哪一种。

### 3. 让层级接管

只删文字通常会让界面变空或变乱。删完补上层级，颜色、字号和组件沿用项目已有的 token：

- 字号和字重区分主次，一屏只有一个最强的焦点。
- 留白和对齐表达分组，相关的靠近，无关的拉开。
- 一层容器为上限；嵌套卡片拍平成留白分组。留白足以分组时，那一层也去掉。一致性指 token 和组件，页面已有的卡片不必保留。
- 次要细节收进 tooltip、展开区或详情抽屉。
- 危险操作与常用操作保持距离，样式也要有区别，按钮写全动作和对象（「删除 billing」）。重排只能让它离常用操作更远。

同步清理被删文案的引用：在 locale 文件和测试断言里搜一遍被删文字和 i18n key，一并移除或更新。

完成标准：搜不到悬空引用；视觉风格与相邻页面一致。

### 4. 验证

运行项目的类型检查和相关测试。浏览器应用用 dev-browser 截改动前后的图，再逐条核对：

- 把截图缩小到看不清小字，主次关系依然能分辨。
- 「必须保留」的每一项仍在，包括空状态、错误状态和加载状态，这些默认看不到，要主动触发或读代码确认。
- 界面比改动前更清晰。如果用户反而要猜含义，把最小必要的标签加回去。

完成标准：以上三条都有截图或代码依据。无法运行应用时，在汇报里写明没有看过实际效果。

### 汇报

一行总结删减数量，然后列出：删了什么、留了什么及理由、哪些拿不准需要用户决定。

## 常见 slop

| 形态 | 例子 | 处理 |
|---|---|---|
| 副标题复述标题 | 「用户管理」下面写「管理您的所有用户」 | 只留标题 |
| 说明书文案 | 「这里展示了您最近的订单」 | 删，内容自己说明 |
| Slogan | 产品内页写「一站式智能协作平台」 | 删 |
| 操作提示 | 「点击下方按钮开始」 | 删，按钮写成动词 + 对象 |
| 重复信息 | 面包屑、页标题、tab 都写同一个名字 | 留一处 |
| 无信息徽章 | 「AI 驱动」「智能」，不区分任何东西的 tag | 删 |
| 常态指示 | 每一行都有绿点「运行正常」 | 缩成弱化的短文字（「正常」），让异常靠对比突出 |
| 卡片套卡片 | 卡片里再放带边框的卡片 | 拍平成一层 + 留白 |
| 装饰填充 | 渐变图标方块、每个标题配 emoji、彩色左边框、渐变文字 | 删，或换成有含义的元素 |
| 编造内容 | 没有数据来源的「较上周 +12%」、虚构的用户评价 | 删，或接真实数据 |

## 必须保留

这些是删除测试的常见「会」，精简时逐条核对：

- **异常状态**：错误、空状态、权限不足，写明原因和下一步。
- **状态列的每一行**：空白会让「未知」和「正常」无法区分。
- **不可逆操作的后果**：删除确认里的影响范围。
- **数据口径**：单位、时间范围、币种，以及定义不明显的指标。
- **表单标签和校验规则**：字段名用常驻 label，placeholder 只作示例。
- **图标的可访问名称**：只有含义通用的图标才去掉可见文字，同时保留 `aria-label` 和 tooltip；含义不通用的保留文字。
- **状态的非颜色表达**：只靠颜色区分时，补文字或形状。
- **法律和合规文案**。
